# Capstone - OvalleStock
Proyecto de Titulo

# Descripción del Proyecto 
Plataforma web responsiva para optimizar la gestión de inventarios de frutas y verduras en el sector de Lo Valledor. El proyecto busca digitalizar los procesos manuales, reduciendo errores y mejorando el control de stock para pequeños y medianos comerciantes. Características Principales Gestión de Inventario: Control de entradas, salidas y stock de productos. Lectura de códigos: Integración de lectores QR y de barras para agilizar el registro. Alertas y reportes: Generación de informes básicos y notificaciones de bajo inventario. Metodología El proyecto se desarrolla utilizando la metodología ágil Scrum, lo que permite un trabajo iterativo y colaborativo. Relevancia Este proyecto aplica competencias clave de la ingeniería informática, como el desarrollo de software y la gestión de bases de datos, para solucionar una problemática real del mercado.
